## git zf issue show

Show an issue stored in the repository and its comments

### Synopsis

Show an issue stored in the repository. &lt;id&gt; is the full ID, the number of
the tracker issue it is mirrored with, or a unique prefix of at least 4 characters.
Without &lt;id&gt; a picker lists the issues.

```
git zf issue show [<id>] [flags]
```

### Options

```
  -h, --help   help for show
      --json   print the issue as JSON
```
