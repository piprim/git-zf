## git zf review status

Show the full review history for an issue

### Synopsis

Pick an issue and print its review round by round: status, reviewer,
timestamps, and whether the reviewer pushed commits. It is read from the
review chain, so it is the same on every clone.

```
git zf review status [flags]
```
