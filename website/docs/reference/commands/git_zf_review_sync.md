## git zf review sync

Bring a sub-task branch up to date with its parent branch

### Synopsis

Pick an in-progress sub-task branch (the current one is pre-selected): the
parent branch (&lt;remote&gt;/&lt;parent&gt;) is merged into it. A conflict is aborted
and reported.

```
git zf review sync [flags]
```
