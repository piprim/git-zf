# User Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Docusaurus 3 site under `website/` that is the user documentation of git-zf, with a command reference generated from the binary, and a README cut down to a pitch and a link.

**Architecture:** The help strings in `cmd/` are expanded first, so that a small Go program (`internal/docgen`, built on `cobra/doc`) can write one Markdown page per command into the site; a Go test fails when those committed pages drift from the code. The hand-written pages are restructured from the README, section by section, and the four refs notes move under "Under the hood". The site is docs-only (`routeBasePath: '/'`), built for the domain root, with an autogenerated sidebar ordered by `_category_.json` files.

**Tech Stack:** Go 1.25, Cobra v1.1.3 (`github.com/spf13/cobra/doc`), Node 24 / npm 11, Docusaurus 3.10.2 classic preset with TypeScript config. All run through `mise exec --` for Go.

**Spec:** `docs/superpowers/specs/2026-10-28-user-documentation-site-design.md`

## Global Constraints

- Every Go test assertion lives in a named `t.Run` (user `CLAUDE.md`); run tests with `mise exec -- go test`.
- `Long` strings are plain text wrapped at 80 columns, no Markdown beyond backticks: they print in the terminal too.
- Commands are written `git zf <sub>` everywhere users read them, never `git-zf <sub>`.
- The site is served from the domain root: `baseUrl: '/'`; `url` is the placeholder `https://example.org` for the author to replace.
- `npm run build` never calls Go. The generated reference pages are committed. Generation is `make docs-gen`.
- Nothing from the README is dropped unless contributor-only, except the upgrade notes (README lines 287 and the "Upgrading from the SQLite store" section of `docs/branch-refs.md`), which are dropped, and the `ROADMAP.md` link (README line 289), replaced by one sentence.
- No renames of commands. `branch close` abandons; `issue close` merges. Every page that names one of the two says so where the reader could confuse them.
- Admonitions only for things that lose data or cannot be undone.
- Hand-written pages: second person, present tense, one idea per sentence; a page opens with what the reader can do after it; terminal sessions are fenced blocks starting with `$ git zf …`; TUI keys in backticks.
- Hand-written and generated pages are `.md`; the site sets `markdown.format: 'detect'` so `.md` is CommonMark and `<IssueID>`, `<id>`, `{issue-id}` in help text and prose do not break the MDX build.

## Review Focus

1. Help text holding `<IssueID>` or `{issue-id}` must build: an MDX parser treats them as JSX. Pinned in Task 3 (the build on the generated pages with `markdown.format: 'detect'`).
2. The generator must not read the author's config: the output of `make docs-gen` must be the same on every machine, or the drift test flaps. Pinned in Task 2 (`TestGenerate/ignores the user config`).
3. The hidden hook commands `review guard` and `review guard-commit` must not get a page. Pinned in Task 2 (`TestGenerate/skips hidden commands`).
4. A moved refs note still linking `../README.md#merge-strategies` must fail the build, not ship a dead link. Pinned in Task 3 (`onBrokenLinks` and broken Markdown links set to `throw`) and exercised in Task 4.
5. A command added later without a `Long` must fail a test, not ship a thin reference page. Pinned in Task 1 (`TestGetRootCmd_help/every visible command has a long description`).

func TestGetRootCmd_help(t *testing.T) {
	root, err := GetRootCmd()
	if err != nil {
		t.Fatalf("GetRootCmd: %v", err)
	}

	t.Run("root long description is the pitch", func(t *testing.T) {
		want := "A TUI powered CLI that wraps a git-flow workflow"
		if !strings.HasPrefix(root.Long, want) {
			t.Errorf("root.Long = %q, want prefix %q", root.Long, want)
		}
	})

	t.Run("every visible command has a long description", func(t *testing.T) {
		var walk func(c *cobra.Command)
		walk = func(c *cobra.Command) {
			for _, sub := range c.Commands() {
				if sub.Hidden || sub.Name() == "help" || sub.Name() == "completion" {
					continue
				}
				if strings.TrimSpace(sub.Long) == "" {
					t.Errorf("%s: no Long description", sub.CommandPath())
				}
				walk(sub)
			}
		}
		walk(root)
	})

	t.Run("long descriptions say git zf, not git-zf", func(t *testing.T) {
		var walk func(c *cobra.Command)
		walk = func(c *cobra.Command) {
			for _, sub := range c.Commands() {
				if strings.Contains(sub.Long, "git-zf ") {
					t.Errorf("%s: Long names the binary as git-zf", sub.CommandPath())
				}
				walk(sub)
			}
		}
		walk(root)
	})
}
